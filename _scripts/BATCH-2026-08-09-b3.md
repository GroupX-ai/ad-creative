# Seedance batch 3 — 2026-08-09, the UGC corrective

Two 15-second ads at **native 720p**, made after Robby's verdict on the first 17:
"most of these are quite dry and not so good," and "I prefer 720P."

Assets: `voicedrop/2026-08-09-seedance-ugc-b3/`, `emailchaser/2026-08-09-seedance-ugc-b3/`.
Prompts: [`seedance-prompts-b3.mjs`](seedance-prompts-b3.mjs).

## What changed, and why

The first 17 failed for one reason: the anti-slop recipe worked so well that every ad
landed in the same register. Quiet, restrained, deadpan, no music, punchline at 25
seconds. Format varied fifteen ways; energy never varied once. The shared realism block
literally ended with "Nobody is enjoying themselves," in all 17.

| | Batch 1 and 2 | This batch |
|---|---|---|
| Performance | deadpan, "nobody is enjoying themselves" | animated, fast, genuinely energised |
| Opening | establishing shot, slow push | opens mid-sentence, face already talking |
| Turn lands | ~25s | ~6s |
| Spec | 30s, 480p upscaled | 15s, **native 720p** |
| Camera | observational third person | UGC selfie, straight down the lens |
| Format | fifteen genre parodies | the format that actually sells on Meta |

It also fixes a strategy error: the account's own banner data says the winners are loud
direct-response and native organic (the whiteboard photo Robby called "best by far").
The first 17 were a third thing, polished-restrained, closest to the polished-corporate
family that has never once been picked. **UGC selfie is the video cousin of that
whiteboard, and the first 17 contained zero examples of it.**

Still no music, deliberately. The old batch was inert because performances were slow,
not because a track was missing, and a score would break the phone-shot illusion these
depend on. The energy comes from pace and performance instead.

## QA

Both watched frame by frame and transcribed. **Both transcripts came back word-perfect**,
with no improvised narration and no stage directions read aloud, which the explicit speech
rule (added after batch 2) is doing its job on.

**One minor wart:** in the VoiceDrop ad the phone screen he holds up carries tiny garbled
glyphs where a caller name would be. It is only legible when zoomed about 3x; at feed size
it reads as an ordinary incoming-call screen. Not worth a $6.93 re-roll, but it is the
"screens stay blank" rule bending, and the fix next time is to specify the phone is held
screen-edge-on or that the call screen shows only the answer and decline circles.

## Before they run

- Captions are burned into the `-captioned.mp4` files; clean 1080p versions are kept if you
  want to caption them yourself.
- Both name the brand out loud and on screen, so neither needs an end card to be legible,
  though one would still help the CTA.
- These are the real test of the native-organic bet on video. Run them against any of the
  first 17 in the same ad set and the answer will be obvious within a few thousand
  impressions.

### Known issues to watch

1. **The VoiceDrop video shows "VoiceDrop" as the caller on the phone screen**, which is the
   wrong mechanic: the prospect calls back, VoiceDrop does not call the user. This is the same
   error the `c22` banner was re-rolled for. The thumbnail was deliberately chosen from 13.0s
   to avoid it, but it is still in the video around 6-10s. Fix on any re-roll by specifying the
   call screen shows only the answer and decline circles.
2. **No Instagram account is exposed on the VoiceDrop ad account** through the connector, so
   `instagram_user_id` was not set on either creative. Existing ads do deliver to Instagram, so
   the link exists at the page level; check IG placement is on in Ads Manager before activating.
3. **Conversion tracking is still degraded** (Meta CAPI dead since ~Apr 27), so read these on
   CTR, hold rate and cost per click first, not on the conversion column.
