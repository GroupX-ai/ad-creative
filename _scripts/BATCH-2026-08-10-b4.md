# Seedance batch 4 — 2026-08-10, stronger hooks and closes

Three 15-second UGC ads at native 720p. Robby: "make sure the hooks and ending CTA is a
bit stronger." Batch 3 proved the format; this batch sharpens both ends of it.

Assets: `voicedrop/2026-08-10-seedance-ugc-b4/`, `emailchaser/2026-08-10-seedance-ugc-b4/`.
Prompts: [`seedance-prompts-b4.mjs`](seedance-prompts-b4.mjs).

## What "stronger" meant in the prompt

| | Batch 3 | This batch |
|---|---|---|
| Hook | opens mid-sentence | opens mid-**gesture**, first line is a fragment carrying a number or a command, first syllable inside 0.5s |
| Close | delivered at the same pace as everything else | explicit gear change: motion stops, delivery slows, eye contact locks, one point at the lens, offer named out loud |

Both are now named prompt blocks (`HOOK`, `CTA`) so every future ad inherits them.

## Two fixes carried in, both verified

1. **The phone-screen mechanic is fixed.** In `c45` the phone read "VoiceDrop" as the caller,
   which inverts the product (the prospect calls back; VoiceDrop never calls the user) and was
   the same error the `c22` banner was re-rolled for. A `PHONE_RULE` block now specifies an
   incoming-call screen with answer and decline circles and no caller label. Verified at 3x
   zoom on `c46`: no brand name. Faint illegible glyphs remain where a name would be, which
   reads as an unreadable contact rather than saying the wrong thing.
2. **Emailchaser now gets the phonetic treatment that fixed 1Lookup.** It had been
   mispronounced twice, "Chacha" in `c16` and "Chaper" in `c18` wave 1, the latter confirmed
   across three transcription engines. A positive-only pronunciation rule (never naming the
   wrong versions, per the banner lesson that negative instructions backfire) fixed it on the
   re-roll: the clip now says "Email Chaser" correctly.

## Caption bug found and fixed this batch

The two VoiceDrop closers rendered **"VOICEDROP.AI" as plain white body text** instead of the
brand tier, because speech-to-text returns the spoken URL as one token that bares to
`voicedropai`, which failed an exact-match brand lookup. That word is the entire CTA payoff.
Brand matching is now containment-based rather than equality-based, and it renders gold at the
brand size, auto-shrunk to 135px so it fits the frame. All three closers were re-checked by
extracting the exact CTA frame.
