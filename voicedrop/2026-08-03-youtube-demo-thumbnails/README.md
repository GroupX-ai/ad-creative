# VoiceDrop 2026-08-03 YouTube demo thumbnails

Three 1280x720 thumbnail options for Brian's VoiceDrop 2.0 setup walkthrough (~9 min), going up on
the VoiceDrop YouTube channel (`youtube.com/@voicedrop-ai`). Requested by Nadav on 2026-07-27 in
`#vd-sales`: upload it, and make sure every new client watches it, especially clients who did not
have a demo call.

Concept numbering continues the VoiceDrop series (C1-C3 in `2026-07-20-banners`, C4-C5 in
`2026-07-27-banners`, C6-C9 in `2026-08-03-billboard-batch`), so these are C10-C12.

## Two things that differ from the rest of this vault

**New format token: `youtube`.** YouTube video thumbnails are 1280x720 (16:9), which is not the
1200x628 `landscape` spec, so a fourth token was added rather than mislabelling these as landscape.
Existing tokens are unchanged.

**Rendered from code, not generated by fal.** These are deterministic HTML/CSS renders screenshotted
by headless Chromium, using the real product logo and the real in-app brand purple. That was the
right call for a thumbnail: image models mangle typography at this size, and a thumbnail lives or
dies on legibility at 246px wide. There is therefore no generation prompt. The reproducible artifact
is `_source/make-thumbnails.mjs` instead, which is a straight swap for the prompt in every other
batch here: edit the `VARIANTS` array, re-run, get the same pixels.

## Claims review

Every claim traces to Brian's own transcript, so nothing here needed the approved-copy bank:

- **"LIVE IN 15 MINUTES"** — Brian at 0:14: "this should take no more than 10-15 minutes, if not faster."
- **"YOU ONLY PAY ON DELIVERY"** — Brian at 7:55: "we only charge upon successful delivery."
- **"SETUP, START TO FINISH"** — describes the video, not the product.

**No callback rate appears on any of the three, deliberately.** The sales training table quoting 5-7%
for real estate and 10-12% for top performers is still wrong and still circulating (open loop in the
`voicedrop` vault note). Real figures are roughly 2% on a dedicated number, about 0.5% in-message, and
5-8% only on warm audiences. Note this differs from the `2026-08-03-billboard-batch` C7 banner, which
uses "9%+ Callback Rate" sourced to verified Trustpilot reviews: that is a cited third-party claim on a
paid ad we can pull, whereas a YouTube video is permanent and public.

## Brand

Deliberately the **in-app** brand system, not the paid-ads one, because a viewer who clicks through
lands on the dashboard and the thumbnail should match what they see next.

- Ground: `#2B2069` to `#1B1440` to `#120E28`, with a `#7C6CF5` aurora behind the mark
- Accent and mark: `#7C6CF5`, highlight blocks reversed to white on `#1B1440`
- Logo: `public/icons/voicedrop-icon.png` from the `VoiceDrop-NodeJS` repo, the real product mark
- Type: Archivo Black (headline), Inter (eyebrow and wordmark), both OFL

This is why there is no `#090714` background or gold `#ffd874` CTA button here. Those are correct for
Meta banners and wrong for a video thumbnail, which has no CTA button at all.

## Reproducing

```bash
# from this folder
mkdir -p fonts
curl -sSL -o fonts/Inter.woff2 \
  "https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2"
curl -sSL -o fonts/ArchivoBlack.woff2 \
  "https://fonts.gstatic.com/s/archivoblack/v23/HTxqL289NzCGg4MzN6KJ7eW6CYyF_g.woff2"

node _source/make-thumbnails.mjs
```

Needs `playwright` and a Chromium build, plus `voicedrop-icon.png` at the path set in the script. The
headline auto-shrinks until the widest line clears the logo, so new copy of any length stays inside
the safe area without hand-tuning.
