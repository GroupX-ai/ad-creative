# teampredict — banner batch 2026-07-01-banners

Paid-social + display banner set for TeamPredict (AI early-warning tool that reads
public LinkedIn signals to flag employee resignation/exit risk weeks in advance).

Delivered as finished creative (not fal-generated) — logged here for archive and reuse.
Source package: `TeamPredict/1 July 2026/` (uploaded 2026-07-22).
Full brand kit, approved claims and guardrails: `AD-CREATIVE-PLAYBOOK.md` in the company's marketing repo.

Two creative rounds of the same "resignation intelligence" campaign:
- **v1** (batch root) — first round.
- **v2** (`v2/`) — refined round: adds a `No credit card required` trust line, a TeamPredict wordmark lockup, and more data-viz-forward risk cards (Day 1 → Day 15 → Day 30 escalation, e.g. 18% → 56% → 91%).

File naming follows the vendor scheme `TP_<placement>_<WxH>_<version>_JUL26.png` (the `×` in the delivered names is normalized to `x`):
- `FB` = Meta feed/landscape/story placements · `GDN` = Google Display Network standard sizes.
- `RT_COL` = Facebook right-column layout variant (same 1200×628 pixels, recomposed).
